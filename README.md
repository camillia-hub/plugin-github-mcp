# GitHub MCP

The official GitHub MCP server. This plugin installs and configures it in your workspaces.

Upstream server docs: https://github.com/github/github-mcp-server

Installs from the Camillia hub as `github-mcp-4d47a2`. On every new task the plugin posts
the ready-to-paste `mcp.servers` entry and the setup steps as a task comment.
